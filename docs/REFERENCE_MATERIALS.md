# Reference Materials

## Purpose

The project reference library lives in [books_and_references](books_and_references/README.md). These books can support Power Up Chess product design, host knowledge, puzzle extraction, curriculum planning, and carefully sourced chess history cards.

## When To Read These Materials

Read the reference folder when working on:

- Puzzle Garden extraction or puzzle source planning.
- Host explanations for chess concepts.
- Curriculum progression for Ada's 300-500 level.
- Famous player or chess history cards.
- Study plans, lesson paths, or review templates.
- Source metadata and rights review.

Do not read or process the full book files for ordinary UI changes, bug fixes, styling work, or unrelated technical tasks.

## Usage Rules

- Treat all books as source references, not publishable app content.
- Do not copy book explanations, diagrams, scans, or long passages into the product unless the license permits it.
- Derived puzzle records must include source metadata and rights status.
- Host facts must be verified and attached to an approved source record.
- Child-facing explanations should be newly written in the selected host voice.
- Large files should not be bundled into the production web app.

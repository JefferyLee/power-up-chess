# Project review — 2026-09-29 (refactor & upgrade plan)

Four-dimension audit (front-end structure, backend/security/deploy,
quality/tooling/perf, docs/product/safety) of the shipped app. Jeff chose
to work through the phases below in order. Tick items as they land.

Numbers at review time: `apps/web/src` 298 files / 50.7k lines,
`functions/src` 133 files / 16.1k lines, 293 commits in 2026 (199 feat),
`public/` 55 MB tracked, initial JS 380 KB gz, web tests 4.3 % of LOC.

## Overall

Strict TypeScript everywhere (0 `as any`), real tests around the rules
layer (chess, engine, hosts, puzzles, siege), default-deny Firestore with
all writes through functions. The debt is in three places: backend
authorisation/privacy gaps, ~1,200 copy-pasted lines across the seven game
screens, and a delivery process that runs from one laptop (CI last ran
2026-07-08).

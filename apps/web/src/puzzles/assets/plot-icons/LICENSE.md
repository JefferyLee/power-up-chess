# Plot icons

Six SVGs (one per Puzzle Garden plot) vendored from
[game-icons.net](https://game-icons.net/), all by the artist **Lorc**
(https://lorcblog.blogspot.com/), released under
[Creative Commons Attribution 3.0 Unported (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

| Plot       | game-icons.net slug      |
| ---------- | ------------------------ |
| mate       | lorc/crown               |
| fork       | lorc/branch-arrow        |
| pinSkewer  | lorc/crossed-chains      |
| sacrifice  | lorc/sacrificial-dagger  |
| endgame    | lorc/pawn                |
| defense    | lorc/bordered-shield     |

Fetched 2026-06-02 from
`https://game-icons.net/icons/ffffff/transparent/1x1/lorc/<slug>.svg`
and post-processed to replace `fill="#fff"` with `fill="currentColor"`
so CSS `color` controls the tint per-card.

Attribution is surfaced in the app via the Theme Shop attribution
section / about page (TODO when one exists).
